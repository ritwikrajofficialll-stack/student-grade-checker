# 🎓 Student Grade Checker

A simple Python project that calculates a student's subject-wise grades, total marks, percentage, and overall grade based on marks obtained in three subjects.

This project is built using basic Python concepts such as user input, conditional statements (`if`, `elif`, `else`), arithmetic operations, and variables.

## ✨ Features

* 🧑 Accepts the student's name.
* 📚 Takes marks in Physics, Chemistry, and Maths/Biology.
* 📊 Calculates total marks out of 300.
* 📈 Calculates the overall percentage.
* 🏆 Assigns individual grades for each subject.
* 🎯 Determines the overall grade based on percentage.
* 💻 Displays the results directly in the terminal.

## 🛠️ Technologies Used

* **Language:** Python
* **Concepts:** Variables, user input, conditional statements, arithmetic operations, and type conversion.

## 📋 Grading System

| Marks / Percentage | Grade |
| ------------------ | ----- |
| 90 and above       | A     |
| 80–89              | B     |
| 70–79              | C     |
| 60–69              | D     |
| Below 60           | F     |

The same grading thresholds are used for individual subjects and the overall percentage.

## 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Student-Grade-Checker.git
```

**2. Open the project folder**

```bash
cd Student-Grade-Checker
```

**3. Run the Python program**

```bash
python Student_Grade_Cheker.py
```

Make sure Python is installed on your system before running the program.
